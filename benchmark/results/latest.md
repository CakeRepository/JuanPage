## Interpretation

For this fixture, M1 is smaller than canonical JuanPage JSON but larger than the neutral component tree and natural-language instructions. It adds validation and materialization work that a producer with canonical JuanPage data does not need. Its value is not universal compactness: it is symbolic semantic transport, trust and capability compilation, locale-stable identity, typed human deltas, receipts, and deterministic projection into the one public UI schema.

## Honest limitations

- Token counts use the documented four-bytes-per-token approximation, not a model-specific tokenizer.
- The component tree is a neutral equivalent representation, not an implementation of a named framework.
- Three timing runs are sufficient only for a CI smoke signal; they are not statistically strong performance claims.
- `renderPage` timing includes JSDOM startup and therefore has wider variance than validation and materialization.
- M1 can be larger than terse natural language for small interfaces and is less convenient for manual authoring.
