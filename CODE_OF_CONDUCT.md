# Code of Conduct

## Our commitment

We commit to a respectful, harassment-free community for everyone, regardless of background, identity, experience, or role. Technical disagreement is welcome. Personal attacks, intimidation, harassment, doxxing, discriminatory language, and bad-faith disruption are not.

## Expected behavior

Be precise, kind, and evidence-driven. Critique ideas and implementations rather than people. Respect security embargoes and private reports. Give credit. Assume good intent while still enforcing protocol and safety boundaries.

## Enforcement

Report conduct concerns through the repository owner's private contact channel or GitHub moderation tools. Maintainers may edit or remove content, issue warnings, temporarily restrict participation, or permanently ban participants when necessary. Enforcement decisions should be documented privately and applied consistently.

This policy applies in repository discussions, pull requests, issues, community spaces, and public representation of the project.
